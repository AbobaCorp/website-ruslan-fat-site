# 🌸 Храм Аянами Рей — сайт Руслана Камазова

Одностраничный фан-сайт про **Руслана Камазова** — главного фаната Аянами Рей, знатока *Neon Genesis Evangelion* и человека, который всегда знает, где ближайший KFC.

Сайт сделан друзьями с любовью. Руслан, привет! Ждём тебя на парах 🍗

---

## ✨ Что есть на сайте

- **Герой-секция** с аватаром, кратким описанием и анимированной статистикой
- **О Руслане** — три карточки: анимешник, ценитель KFC, фанат Рей
- **Шрин Аянами Рей** — рейтинг любимых образов Рей (Plugsuit, школьная форма, бинты и др.)
- **Генератор вечера** — случайные идеи идеального аниме-вечера
- **Рекорды** — марафоны Evangelion, вёдра KFC и посещённые пары
- **Покормить Руслана** — интерактивный счётчик вёдер KFC с анимацией «дождя» из эмодзи

---

## 🛠 Технологии

- Чистый HTML5
- CSS3 (кастомные свойства, grid, анимации, `prefers-reduced-motion`)
- Ванильный JavaScript (без фреймворков)

Никаких сборщиков и зависимостей — просто открой `index.html` в браузере.

---

## 🚀 Как запустить

1. Скачай или клонируй проект.
2. Открой файл `index.html` в любом современном браузере.
